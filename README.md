# Student Admit Management System

Java Swing desktop application for student admission management.

## Project files
- StudentAdmitManagementSystem.java
- LoginPage.java
- PersonalDetailsPage.java
- DocumentUploadPage.java
- CourseDetailsPage.java
- ApplicationStatusPage.java
- Database.java

## Run in VS Code
1. Install a JDK (Java 17+ recommended).
2. Install the Java Extension Pack in VS Code.
3. Add the SQLite JDBC driver (`org.xerial:sqlite-jdbc`) to the project classpath.
4. Open this folder in VS Code.
5. Compile/run `StudentAdmitManagementSystem.java`.

The SQLite database is created as `data.db` in the application's working directory.
